# Level & XP Rank System (nVault)

> AMX Mod X Counter-Strike 1.6 Plugin generated with **SHEVX AMXX Studio**.

## Overview
Create an XP and Level rank system for CS 1.6 saved persistently using nVault by SteamID/AuthID. Players gain 10 XP on kill, 25 XP on headshot, 30 XP on bomb plant/defuse. Ranks from Level 1 (Recruit) to Level 20 (General). Display current Level, XP, and rank name in bottom HUD.

- **Target AMXX Version**: 1.8.2
- **Created**: 17/10/2026
- **Files**: level___xp_rank_system__nvault_.sma

## Installation
1. Compile the `.sma` file using the **AMX Mod X 1.8.2** compiler.
2. Place the resulting `.amxx` file in your server's `cstrike/addons/amxmodx/plugins/` folder.
3. Add the plugin filename to `cstrike/addons/amxmodx/configs/plugins.ini`.
4. If multilingual files (`.txt`) are included, place them into `cstrike/addons/amxmodx/data/lang/`.
5. Restart your server or change the map.
